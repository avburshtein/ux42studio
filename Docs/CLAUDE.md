# UX42 Studio & Portfolio Platform (AI Router & Engineering Guidelines)

Ты — главный системный архитектор и разработчик проекта **UX42.studio**.
Архитектура проекта включает:

1. **Основной сайт студии (UX42.studio):** Презентация услуг студии («UX42.studio»), пакетов (Start & Go, Business Growth), услуг Vibe Coding и юридического комплаенса Испании (RGPD / EAA 2025).

2. **Мультиарендную платформу портфолио (UX42 Portfolios / SaaS-Engine):** Масштабируемую систему конструктора и конструктор формы кейсов (Case Template Engine) для авторов на поддоменах/роутах основного домена (`ux42.studio/u/[username]`).

Цели и особенности проекта

Цель: Запуск бесплатного/минимального по затратам MVP-сервиса портфолио для дизайнеров с публичным каталогом и приватной админкой.

Регистрация по приглашениям: Закрытый доступ на основе инвайт-кодов для контроля качества платформы на этапе MVP.

Изолированная суперадминка: Полная защита интерфейса управления платформой на сетевом уровне с помощью Cloudflare Zero Trust без написания собственной сложной логики авторизации для админа.

Адаптация под Free Tier: Оптимизация архитектуры под бесплатные лимиты Cloudflare (D1 + R2), гарантирующая нулевую стоимость хостинга и отсутствие платы за исходящий трафик (no egress fees).

## 🚫 СТРОГИЕ ПРАВИЛА И ОГРАНИЧЕНИЯ (ENGINEERING CONSTRAINTS)

- **ЗАПРЕЩЕНЫ** инлайн-стили (`style={{ ... }}`).
- **ЗАПРЕЩЕН** хардкод HEX-цветов (например `#0B6E4F`). Все цвета берутся строго из CSS-переменных темы (`var(--md-sys-color-primary)` и т.д.) или Tailwind-классов токенов.
- **ЗАПРЕЩЕНО** менять выравнивание и иерархию сетки layout shift (например, при появлении ошибок во введенных полях всегда резервируется helper text space).
- **Vibe Coding Protocol:** Вся верстка генерируется в виде чистого React + Tailwind CSS кода (через v0 / Cursor). Избегать избыточных оберток (overcoding).

## 🎨 ТЕХНОЛОГИЧЕСКИЙ СТЕК И ДИЗАЙН-СИСТЕМА

### Стек:

Технологический стек

Фронтенд и Админка: Next.js (App Router, Server Actions) — единый монолит для публичной части, панели дизайнера /admin и суперадминки /super-admin.

База данных: Cloudflare D1 (Serverless SQLite на Edge) — высокоскоростное чтение с нулем задержек для публичных страниц.

ORM: Drizzle ORM — полная строгая типизация TypeScript, интеграция с D1 и управляемые миграции.

Хранилище медиа: Cloudflare R2 — объектное хранилище для аватаров, обложек и галерей проектов.

Безопасность суперадминки: Cloudflare Zero Trust (Access) — периметральная авторизация для маршрутов /super-admin/\*.

Деплой и Сборка: Cloudflare Pages / Workers via @opennextjs/cloudflare.

Стилизация: Tailwind CSS v4 + цвета из Material Design 3 (Material You Tokens).

Компоненты: shadcn (на основе radix UI), копированные в кастомный UI, со стилизацией из токенов.

Иконки: `lucide-react` (использование `@mui/icons-material` запрещено).

### Ключевые токены цвета (Material Design 3 Seed: `#0B6E4F`):

- **Primary:** Forest Green (`#0B6E4F` / CSS var: `--md-sys-color-primary`) — Личность бренда, действия.
- **Secondary:** Coral Red (`#FF6467` / CSS var: `--md-sys-color-secondary`) — Акценты, ключевые вызовы.
- **Tertiary:** Off-white (`#FBFFFA`) — Нейтральные фоновые подложки.
- **Error:** Amber Warning (`#D17D00`) — Ошибки, предупреждения.
- **Fonts:** Poppins (Заголовки), Inter (Основной текст).

## 🏗 АРХИТЕКТУРА МУЛЬТИАРЕНДНОЙ ПЛАТФОРМЫ ПОРТФОЛИО

Платформа спроектирована с учетом масштабирования для друзей/дизайнеров:

### Динамический роутинг:

Компактный реестр всех роутов приложения, сгруппированный по типам доступа и функциональности:

**Публичная часть (Public)**

- `GET /` — Главная страница (каталог дизайнеров и избранных проектов)
- `GET /u/[user-slug]` — Публичный профиль дизайнера + сетка его проектов
- `GET /u/[user-slug]/[project-slug]` — Страница конкретного проекта

**Аутентификация и регистрация (Auth)**

- `GET /login` — Страница входа для дизайнеров
- `GET /register?invite=[code]` — Страница регистрации по инвайту

**Админка дизайнера (User Admin: `/admin/*`)**

- `GET /admin` — Дашборд: список своих проектов
- `GET /admin/projects/new` — Создание нового проекта
- `GET /admin/projects/[id]/edit` — Редактирование проекта и загрузка галереи
- `GET /admin/profile` — Настройки профиля (аватар, bio, соцсети)

**Суперадминка (Cloudflare Zero Trust: `/super-admin/*`)**

- `GET /super-admin` — Обзорная статистика платформы
- `GET /super-admin/users` — Список всех пользователей (блокировка, поиск)
- `GET /super-admin/invites` — Генерация и менеджмент инвайт-ссылок
- `GET /super-admin/projects` — Модерационный список всех проектов

**Внутренние API-эндпоинты / Server Actions (API)**

- `POST /api/upload` — Direct upload в Cloudflare R2 (получение presigned URL или прямой прокси)
- `GET /api/health` — Проверка статуса сервиса / D1 / R2

### Поток создания кейса (`Case Template Engine`), основные секции:

Форма автозаполнения и сборки кейсов строится строго по схеме 7 секций:

1. **01 Intro & Meta:** Title, URL Slug, Category, Client, Year, Duration, Role, Prototypes, Hero Image.
2. **02 Problem & Audience:** Формулировка проблемы, ЦА, ключевые метрики.
3. **03 User Research:** Методология, Персона, User Story.
4. **04 Design Process:** Подход к проектированию, вайрфреймы, интерфейсы.
5. **05 Testing & Iteration:** Сравнение Before / After, A/B тесты.
6. **06 Final Showcase:** Галерея скриншотов, интерактивные прототипы, инструменты.
7. **07 Reflection & Next Steps:** Главный вывод, отзыв клиента, дальнейшие шаги.
