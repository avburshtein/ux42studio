## 🎨 Как заменить на реальные изображения

1. Добавьте ваши изображения в `/public/images/`
2. Откройте `/src/imports/HomeDesktop.tsx`
3. Замените пути:
   ```typescript
   // Было:
   const imgAvatarImage = '/images/avatar.svg'
   
   // Станет:
   const imgAvatarImage = '/images/team-photo.jpg'
   ```
4. Запустите `npm run dev` для проверки
