# ✅ Чеклист подготовки к деплою

## 📋 Перед деплоем проверьте:

### 1. Код и функциональность
- [ ] Все страницы работают корректно
- [ ] Навигация между страницами работает (/, /portfolio, /privacy, /terms, /cookies)
- [ ] Модальные окна открываются и закрываются
- [ ] Темная тема переключается корректно
- [ ] Мобильное меню работает
- [ ] Формы валидируются
- [ ] Все кнопки кликабельны и ведут куда нужно
- [ ] Анимации работают плавно

### 2. Контент
- [ ] Замените placeholder тексты на реальный контент
- [ ] Проверьте все изображения загружаются
- [ ] Обновите мета-теги в `index.html`:
  - [ ] `<title>` - название сайта
  - [ ] `<meta name="description">` - описание
  - [ ] Open Graph теги (og:title, og:description, og:image)
  - [ ] Twitter Card теги
- [ ] Обновите URL в `sitemap.xml` на реальный домен
- [ ] Обновите домен в `robots.txt`

### 3. SEO и производительность
- [ ] Favicon добавлен (пока используется стандартный Vite)
- [ ] robots.txt настроен
- [ ] sitemap.xml настроен
- [ ] Мета-теги для социальных сетей заполнены
- [ ] Изображения оптимизированы (не слишком большие)

### 4. Конфигурация
- [ ] `.env.example` настроен (если используются переменные окружения)
- [ ] `package.json` содержит корректное название и описание
- [ ] `.gitignore` исключает ненужные файлы
- [ ] Все зависимости установлены (`npm install`)

### 5. Сборка
- [ ] Проект собирается без ошибок: `npm run build`
- [ ] Preview работает корректно: `npm run preview`
- [ ] Размер bundle разумный (dist папка не больше 5-10 MB)
- [ ] В консоли браузера нет критических ошибок

### 6. Git и GitHub
- [ ] Код закоммичен: `git status` показывает "clean"
- [ ] Создан GitHub репозиторий
- [ ] Код запушен на GitHub: `git push`
- [ ] README.md актуален и информативен

### 7. Хостинг конфигурация
- [ ] `vercel.json` присутствует (для Vercel)
- [ ] `netlify.toml` присутствует (для Netlify)
- [ ] `.github/workflows/deploy.yml` присутствует (для GitHub Pages)
- [ ] `public/_redirects` присутствует

### 8. Безопасность
- [ ] Нет хардкодных API ключей в коде
- [ ] Секретные данные в `.env` (который в `.gitignore`)
- [ ] `.env` файл НЕ закоммичен

## 🚀 Готовы к деплою?

Если все пункты отмечены - вы готовы!

### Выберите платформу:

**Vercel (Рекомендуется для начинающих):**
```bash
# Через веб-интерфейс
1. Зайдите на vercel.com
2. Импортируйте GitHub репозиторий
3. Нажмите Deploy
```

**Netlify (Самый быстрый):**
```bash
npm run build
# Перетащите папку dist на netlify.com/drop
```

**GitHub Pages (Бесплатный):**
```bash
# Настройте GitHub Pages в Settings → Pages
# Выберите GitHub Actions как source
git push
# Деплой произойдет автоматически
```

## 📈 Следующие шаги:

1. **Настройте домен** (если есть)
   - В Vercel: Settings → Domains
   - В Netlify: Site settings → Domain management

2. **Добавьте аналитику** (опционально)
   - Google Analytics
   - Vercel Analytics
   - Netlify Analytics

3. **Настройте мониторинг** (опционально)
   - UptimeRobot для проверки доступности
   - Sentry для отслеживания ошибок

4. **Сделайте backup**
   - GitHub уже является backup кода ✅
   - Настройте автоматические бекапы на хостинге

## 🆘 Проблемы?

Если что-то не работает:

1. Проверьте логи билда в панели хостинга
2. Откройте DevTools (F12) → Console для поиска ошибок
3. Проверьте Network tab для failed запросов
4. Посмотрите [DEPLOY.md](./DEPLOY.md) раздел "Проблемы и решения"
