## 📋 Что нужно сделать перед деплоем

### Обязательно:
1. ✏️ Обновите URL в `index.html`:
   - Замените `https://yourdomain.com/` на реальный URL
   - Во всех meta тегах (og:url, twitter:url)

2. ✏️ Обновите URL в `sitemap.xml`:
   - Замените `https://yourdomain.com/` на реальный домен

3. ✏️ Обновите robots.txt:
   - Замените URL sitemap на реальный

### Опционально:
4. 🎨 Добавьте свой favicon (пока используется стандартный Vite)
5. 📸 Создайте og-image.jpg для социальных сетей (1200x630px)
6. ✏️ Обновите `package.json`:
   - Измените `name` на название проекта
   - Добавьте `description`
7. 🔑 Создайте `.env` если используете API (скопируйте `.env.example`)
