## 🆘 Нужна помощь?

### Проблемы с деплоем:
1. Проверьте [DEPLOY.md](./DEPLOY.md) → "Проблемы и решения"
2. Посмотрите логи билда в панели хостинга
3. Откройте DevTools (F12) → Console

### Проблемы с разработкой:
1. Проверьте [README.md](./README.md)
2. Убедитесь что все зависимости установлены: `npm install`
3. Очистите кеш: `rm -rf node_modules && npm install`
