## 🎨 Как сделать скриншоты

### Метод 1: Браузер (простой способ)

```bash
# 1. Запустите проект локально
npm run dev

# 2. Откройте http://localhost:5173

# 3. Для Desktop (1920x1080):
- F12 → Console → Вставьте:
document.body.style.width = '1920px'

# 4. Для Mobile (375x812):
- F12 → Device Toolbar (Ctrl+Shift+M)
- Выберите iPhone 12 Pro

# 5. Сделайте скриншот:
- Windows: Win + Shift + S
- Mac: Cmd + Shift + 4
- Linux: Shift + PrtScn
```

### Метод 2: Инструменты (профессиональный)

**Рекомендуемые инструменты:**

1. **Figma** (бесплатно)
   - File → Import → From URL: http://localhost:5173
   - Автоматически импортирует весь сайт

2. **ScreenshotAPI** (бесплатно 100/месяц)
   - https://screenshotapi.net
   - Высокое качество, разные размеры

3. **Chrome DevTools**
   - F12 → Ctrl+Shift+P → "Capture full size screenshot"
   - Захватывает всю страницу

### Метод 3: Специальные расширения

**Chrome Extensions:**
- **GoFullPage** - скриншоты всей страницы
- **Awesome Screenshot** - с аннотациями
- **Nimbus Screenshot** - с записью видео
