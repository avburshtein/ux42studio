# 🎯 Сравнение методов импорта в Figma

## Что даёт каждый метод:

---

## Метод 1: Design Tokens (Tokens Studio)

### ✅ Что импортируется:
- **Color Styles** (30+ стилей)
- **Variables** (цвета для Light/Dark режимов)
- **Spacing Values** (4px, 8px, 12px... 112px)
- **Border Radius Values** (24px, 48px, etc.)
- **Typography Values** (размеры шрифтов, line-height)

### ❌ Что НЕ импортируется:
- ❌ Готовые компоненты (Button, Card, Input)
- ❌ Text Styles (нужно создать вручную)
- ❌ Effect Styles (shadows)
- ❌ Auto Layout структуры

### 🎯 Итого:
**Вы получаете "ингредиенты"** - цвета, размеры, отступы.  
**Компоненты нужно собрать самому** (но быстро, т.к. стили уже есть).

**Время:**
- Импорт токенов: 2 минуты
- Создание компонентов: +20-30 минут
- **Итого: ~30 минут**

---

## Метод 2: html.to.design (импорт с сайта)

### ✅ Что импортируется:
- **Готовые визуальные элементы** (кнопки, карточки, формы)
- **Все стили применены** (цвета, шрифты, тени)
- **Auto Layout** (padding, gap)
- **Структура элементов**

### ⚠️ Особенности:
- Импортируются как **обычные frames**, не Components
- Нужно вручную конвертировать в Components (1 клик)
- Стили "запечены" в элементах (не как Variables)

### ❌ Что НЕ импортируется:
- ❌ Figma Variables
- ❌ Переиспользуемые Color/Text Styles
- ❌ Variants (нужно создать вручную)

### 🎯 Итого:
**Вы получаете готовые визуальные элементы.**  
**Можно сразу использовать,** но для масштабирования нужно конвертировать в компоненты.

**Время:**
- Импорт с сайта: 5 минут
- Конвертация в Components: +10 минут
- **Итого: ~15 минут**

## 📋 Пошаговая инструкция КОМБО-метода:

### Этап 1: Импорт токенов (2 минуты)

```
1. Figma → Plugins → Tokens Studio for Figma
2. Load from JSON → /design-tokens.json
3. Import

✅ Получили: Variables для цветов, spacing, radius
```

### Этап 2: Импорт элементов (5 минут)

```
1. Терминал: npm run dev
2. Figma → Plugins → html.to.design
3. Import from URL: http://localhost:5173
4. Выберите:
   - Кнопки из Hero секции
   - Карточки Portfolio
   - Форму Contact
   - Input поля
5. Import

✅ Получили: Визуальные элементы с правильными стилями
```

### Этап 3: Конвертация в компоненты (5 минут)

```
1. Выберите импортированную кнопку
2. Right click → Create Component (или Cmd/Ctrl + Alt + K)
3. Назовите: "Button"
4. Создайте Variants:
   - Добавьте Property "Variant": Primary, Secondary, Ghost
   - Добавьте Property "Size": Large, Medium, Small

5. Замените "запечённые" цвета на Variables:
   - Выберите Background fill
   - Вместо #0b6e4f → выберите Variable "Primary/Green"

6. Повторите для Card, Input, Badge

✅ Получили: Переиспользуемые компоненты с Variables
```

### Этап 4: Создание Text Styles (5 минут)

```
Это нужно сделать вручную, но быстро:

1. Создайте Text frame
2. Установите: Poppins Medium, 52px
3. Right click → Create Text Style → "H1/Desktop"
4. Повторите для H2, H3, H4, Body

Или используйте плагин Scripter с кодом из FIGMA_AUTOMATION.md
```

### Этап 5: Создание Effect Styles (5 минут)

```
1. Создайте Rectangle
2. Effects → Drop Shadow:
   - X:4 Y:4 Blur:2 rgba(0,0,0,0.05)
3. Right click → Create Effect Style → "Card/Light"
4. Повторите для других теней

Значения возьмите из FIGMA_CHEATSHEET.md
```
