## ⚡ Быстрые действия (5 минут)

### Шаг 1: Откройте Case Study

```bash
# В браузере откройте:
http://localhost:5173/case-study.html

# Или напрямую файл:
open public/case-study.html
```

### Шаг 2: Экспортируйте в PDF

**Способ 1 - Браузер (проще всего):**
```
1. Откройте case-study.html в Chrome/Firefox
2. Ctrl+P (или Cmd+P на Mac)
3. Destination → Save as PDF
4. Сохраните → case-study.pdf
```

**Способ 2 - Разбить на изображения:**
```
1. Откройте case-study.html
2. F12 → Ctrl+Shift+P → "Capture screenshot"
3. Сохраните каждую страницу отдельно
```

### Шаг 3: Сделайте скриншоты сайта

```bash
# Запустите проект
npm run dev

# В браузере:
1. F12 → Ctrl+Shift+M (mobile view)
2. Выберите размер: 1920x1080 (Desktop) или 375x812 (Mobile)
3. Сделайте скриншот: Win+Shift+S (Windows) или Cmd+Shift+4 (Mac)
```

**Нужные скриншоты (минимум 8):**
- ✅ Главная страница (Light)
- ✅ Главная страница (Dark)
- ✅ Портфолио секция
- ✅ Открытое модальное окно
- ✅ Форма контактов
- ✅ Мобильная версия (закрытое меню)
- ✅ Мобильная версия (открытое меню)
- ✅ Компоненты Design System

## 📤 Загрузка на Contra

### 1. Регистрация
- Перейдите: https://contra.com
- Sign Up → Create Profile

### 2. Создание проекта
```
1. Profile → Add Work → New Project
2. Upload 5-10 изображений
3. Title: "Modern Design Studio Website"
4. Description: скопируйте из /PORTFOLIO_PRESENTATION.md раздел "Contra Description"
5. Role: Designer & Developer
6. Duration: 2 weeks
7. Year: 2026
8. Tags: React, TypeScript, Tailwind CSS, Web Design, UI/UX
9. Add Link: [ваш live URL]
10. Publish!
```
