# 🖼️ Локальные изображения проекта

Эта папка содержит локальные SVG изображения, используемые вместо `figma:asset` импортов.

## Файлы изображений

### 1. `avatar.svg`
- **Назначение**: Аватары пользователей
- **Размер**: 80×80px
- **Стиль**: Иконка пользователя с кругом и силуэтом
- **Использование**: В карточках команды, отзывах

### 2. `placeholder.svg`
- **Назначение**: Общие placeholder изображения
- **Размер**: 400×400px
- **Стиль**: Простой серый блок с текстом "Image"
- **Использование**: Для любых изображений по умолчанию

### 3. `design-work.svg`
- **Назначение**: Изображение дизайн-работ
- **Размер**: 600×400px
- **Стиль**: Градиент с сеткой блоков и надписью "Design Work"
- **Использование**: В портфолио, примерах работ

### 4. `team-member.svg`
- **Назначение**: Карточка члена команды
- **Размер**: 80×80px
- **Стиль**: Иконка профиля с текстовыми линиями
- **Использование**: В секции команды

### 5. `collaboration.svg`
- **Назначение**: Концепция сотрудничества
- **Размер**: 600×400px
- **Стиль**: Три профиля с линиями текста
- **Использование**: В секциях о сотрудничестве

### 6. `digital-interaction.svg`
- **Назначение**: Цифровое взаимодействие
- **Размер**: 600×400px
- **Стиль**: Десктоп и мобильное устройство с брендовыми цветами
- **Использование**: В секциях о цифровых решениях

## Замена изображений

### Чтобы заменить placeholder изображения на реальные:

1. **Добавьте ваши изображения** в эту папку `/public/images/`
2. **Обновите импорты** в `/src/imports/HomeDesktop.tsx`:

```typescript
// Было:
const imgAvatarImage = '/images/avatar.svg'

// Станет:
const imgAvatarImage = '/images/your-avatar.jpg'
```

3. **Поддерживаемые форматы**: 
   - SVG (векторная графика, масштабируется без потери качества)
   - PNG (с прозрачностью)
   - JPG/JPEG (для фотографий)
   - WebP (современный формат с лучшим сжатием)
