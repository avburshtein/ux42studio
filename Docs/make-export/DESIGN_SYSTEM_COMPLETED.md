## 📊 Что описано

### Цветовая система
- **Брендовые цвета**: `#0b6e4f` и `#2c5a07`
- **Градиент**: `linear-gradient(107.879deg, ...)`
- **Светлая тема**: background, text, borders
- **Темная тема**: все переменные с `dark:` префиксом
- **Семантические цвета**: destructive, accent, muted

### Компоненты
1. **Кнопки**: Primary (gradient), Secondary (outline), Icon
2. **Карточки**: Стандартные, с hover эффектами
3. **Input поля**: Text, Textarea
4. **Модальные окна**: Базовая структура
5. **Теги/Chips**: С градиентом
6. **Фильтры/Табы**: С активным состоянием

### Spacing система
- **Минимальные**: 8px, 12px, 16px
- **Средние**: 24px, 32px, 48px
- **Крупные**: 64px, 96px, 120px
- **Input padding**: `px-[32px] py-[16px]`
- **Button padding**: 3 размера

### Border Radius
- `6px` - минимальное
- `24px` - карточки, модалки
- `48px` - кнопки, инпуты, теги
- `full` - круглые элементы

### Анимации
- Стандартный transition: `300ms`
- Длительный: `500ms`
- Hover scale: `1.05` (кнопки), `1.02` (карточки)
- Active scale: `0.95`
- Keyframes: `fadeIn`, `scaleIn`

## 🎨 Примеры применения

### Primary Button
```tsx
<button className="px-[32px] py-[16px] rounded-[48px] text-white 
  shadow-[2px_2px_4px_0px_rgba(0,0,0,0.1)] 
  transition-all duration-300 hover:scale-105 active:scale-95"
  style={{backgroundImage: "linear-gradient(107.879deg, rgba(11, 110, 79, 0.9) 3.7608%, rgba(44, 90, 7, 0.9) 98.529%)"}}
>
  Click me
</button>
```

### Card Component
```tsx
<div className="bg-white dark:bg-[rgba(30,30,30,0.9)] rounded-[24px] p-[32px] 
  shadow-[4px_4px_12px_0px_rgba(0,0,0,0.1)] transition-colors duration-300"
>
  Content
</div>
```
