### 3.1 Что именно «404» — это сканеры, не баги

Топ путей с 404 за 7 дней:

```
/.env              81   /old/.env          56   /ccc.php          44
/@fs/.env          63   /info.php          54   /dev/.env         43
/admin.php/2P.php  60   /                  52   /.aws/credentials 41
                       /proc/self/environ (path traversal)        48
/.env.staging 38  /.git/config 38  /staging/.env 37  /.env.production 34
```

Это **чужие** пути: WordPress, PHP-шеллы, `.env`, Git-репозитории, обходы
через `../`. У сайта Next.js — ничего из этого не существует → 404.
Такой шум типичен для любого публичного сайта и **никаких действий не требует**.

Отдельная проверка главной `/`: её 52 «404» распределены **по 1–2 в час**
все 7 дней (кластера нет) — фоновый шум сканеров, а не поломка.

Доля сканеров видна и в топ-40 страниц: после реальных маршрутов
(`/`, `/login`, `/privacy`, `/terms`, `/admin`, `/u/…`) идут `.env*`,
`*.php`, `.git/*`, `/graphql` — около 20 позиций из 40.

## 4. ⚠️ 504 — всплески при деплоях

153 таймаута, но они **не равномерные**:

```
29.09 05:00 UTC → 44 шт   ┐
29.09 07:00 UTC → 48 шт   ┘ окно недоступности ~1.5 ч
30.09 01:00 UTC → 20 шт     ночное окно
всё прочее     → фон 1–8 в час
```

Это окна недоступности origin во время деплоев 29–30.09.2026 (крупных
всплесков после 30.09 нет). Вывод: не системная проблема, но при деплоях
в рабочее время заложите, что 1–2 минуты возможны 504.

## 9. Как повторить: GraphQL-запросы

Эндпоинт: `POST https://api.cloudflare.com/client/v4/graphql`
(Bearer-токен `wrangler`, зона `830ffcef3f865dfaea985594c4b82720`).

Всего запросов за период:

```graphql
query ($zoneTag: string!, $start: Time!, $end: Time!) {
  viewer { zones(filter: { zoneTag: $zoneTag }) {
    httpRequestsAdaptiveGroups(
      filter: { datetimeHour_geq: $start, datetimeHour_leq: $end }
      limit: 5
    ) { count }
  }}
}
```

Коды ответов / топ страниц / страны (подставить измерение):

```graphql
query ($zoneTag: string!, $start: Time!, $end: Time!) {
  viewer { zones(filter: { zoneTag: $zoneTag }) {
    httpRequestsAdaptiveGroups(
      filter: { datetimeHour_geq: $start, datetimeHour_leq: $end }
      limit: 40
      orderBy: [count_DESC]
    ) { count dimensions { edgeResponseStatus } }
  }}
}
```

Работающие измерения: `edgeResponseStatus`, `originResponseStatus`,
`clientRequestPath`, `clientCountryName`, `cacheStatus`, `datetimeHour`.
Нет в схеме (проверено 05.10.2026, отдают `unknown field`): `path`,
`responseStatus`, `clientRequestHost`, `clientBotClass`. Интроспекция
(`__type`) закрыта — возвращает `null`.

События почтовой маршрутизации (диапазон — **не шире 4w3d**, иначе
`cannot request a time range wider than 4w3d`):

```graphql
query ($zoneTag: string!, $start: Time!, $end: Time!) {
  viewer { zones(filter: { zoneTag: $zoneTag }) {
    emailRoutingAdaptive(
      filter: { datetime_geq: $start, datetime_leq: $end }
      limit: 50
      orderBy: [datetime_DESC]
    ) { datetime from to subject status action messageId errorDetail spf dkim }
  }}
}
```
