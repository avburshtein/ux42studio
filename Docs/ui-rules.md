# UX42 UI Implementation Rules (`docs/ui-rules.md`)

> *touch*Назначение:** Документ задает инженерные правила верстки, работу с сеткой, гибкими лейаутами и интерактивными элементами интерфейса для проекта **UX42.studio** и конструктора кейсов.
> **Принцип:** Никаких ad-hoc решений. Все отступы, сетки и структуры строго подчинены системе токенов M3 и Tailwind v4.

---

## 1. Сетка, Анатомия Отступов и Отклики (Layout & Spacing)

Вся пространственная верстка строится на фундаментальной 4px сетке.

### 1.1 Стандартные шаги отступов во фреймворке:

* **`p-1` / `gap-1` (4px):** Микро-выравнивание, стыки компонентов, отступы иконок от внутренних границ.
* **`p-2` / `gap-2` (8px):** Расстояние между иконкой и текстом, внутренние зазоры чипсов и бейджей.
* **`p-3` / `gap-3` (12px):** Паддинги компактных элементов, плотные списки полей.
* **`p-4` / `gap-4` (16px):** Каноничный внутренний отступ для кнопок, стандартизированный отступ карточек.
* **`p-5` / `gap-5` (20px):** Внутренние отступы секций формы конструктора кейсов, карточек услуг.
* **`p-6` / `gap-6` (24px):** Паддинги контейнеров аккордеонов, безопасные боковые отступы мобильных экранов.
* **`p-8` / `gap-8` (32px) и `p-12` / `gap-12` (48px):** Межсекционные интервалы и отступы сетки макетов.

### 1.2 Защита от Layout Shift (CLS Blocking)

* Для всех полей ввода (`Input`, `Textarea`, `Select`) зарезервирована зона под вспомогательный текст / ошибки (`min-height: 76px`).
* Появление предупреждающего сообщения или ошибки **не должно сдвигать** нижележащие элементы формы.

## 2. Анатомия Форм и Радиусов (Shapes & Surfaces)

В UX42 форма несет характер дружелюбного, но технологичного инжиниринга. Острые углы используются только для структурных сепараторов, все интерактивные поверхности имеют четко выверенный радиус.

### 2.1 Иерархия скруглений:

* **Поля ввода и интерактивные контролы:** `rounded-[12px]` (`var(--md-sys-shape-corner-medium)`).
* **Кнопки действий и чипсы:** `rounded-[14px]` или `rounded-full` (капсулы) в зависимости от контекста.
* **Карточки секций и аккордеоны конструктора:** `rounded-[20px]` (`var(--md-sys-shape-corner-large)`).
* **Модальные окна, штоки (Drawers):** `rounded-t-[28px]` / `rounded-[28px]` (`var(--md-sys-shape-corner-extra-large)`).

## 3. Каркас Страниц и Адаптивность (Grid & Responsiveness)

Интерфейс UX42 адаптируется под три ключевых брейкпоинта:

| Брейкпоинт | Ширина экрана | Контейнер формы | Поведение Layout |
| --- | --- | --- | --- |
| **Desktop** | `≥ 1024px` | `850px` (центрированный) | 2–3 колонки в сетках метрик и галерей |
| **Tablet** | `768px – 1023px` | `100%` (padding 24px) | 2 колонки в сетках, адаптивные аккордеоны |
| **Mobile** | `< 768px` | `100%` (padding 16px) | 1 колонка, плавающие кнопки фиксации |

---

## 4. Режимы Оформления Карточек и Границ (Theme Adaptation)

### 4.1 Светлая тема (`Light Theme`):

* Поверхности карточек имеют белый фон (`var(--md-sys-color-surface)`).
* Контур карточек задается тонкой полупрозрачной рамкой: `border: 1px solid var(--md-sys-color-outline-variant)`.
* Глубина создается за счет легких мягких теней M3 (`.md-elevation-1`).

### 4.2 Тёмная тема (`Dark Theme` / `.dark`):

* Эффект Elevation нейтрализуется для предотвращения серых «грязных» пятен.
* Границы элементов подсвечиваются мягким адаптивным контуром:
`border: 1px solid color-mix(in srgb, var(--md-sys-color-outline) 20%, transparent)`.
* Текст внутри поверхностей строго подчинен переменной `var(--md-sys-color-on-surface)`.

## 5. Реестр Компонентов и Правила Переиспользования

Перед импортом или созданием нового компонента сверяйся с этой таблицей:

| Элемент интерфейса | Исходник / Подход | Правило применения |
| --- | --- | --- |
| **Кнопки (Primary, Secondary, Ghost)** | React Aria + Tailwind | Только семантические M3 токены. Никаких хардкодных цветов. |
| **Поля формы (Input / Textarea)** | Кастомный UI компонент | Обязательный `min-height`, поддержка `aria-required`. |
| **Аккордеон секций конструктора** | Кастомный UI с `lucide-react` | Скругление `20px`, анимация разворачивания по выравниванию. |
| **Метрики (Metric Cards)** | Grid 3 колонки (1 в mobile) | Крупное число (Poppins Bold), мелкая подпись (Inter Regular). |
| **Иконки приложения** | `lucide-react` | Запрещено использовать `@mui/icons-material`. Строго `lucide-react`. |
| **Хедер и Навигация (Breadcrumbs)** | Flex с фиксированной высотой | Высота `52px`, кнопки назад с габаритом клика `≥ 44x44px`. |
