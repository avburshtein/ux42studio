## Почему документ упразднён

Правила ниже описывали ранний этап проекта и **расходились с кодом**. Историческая
сверка (что именно устарело):

| Было здесь | Стало в `Docs/design-system.md` / в коде |
| --- | --- |
| Тема переключается классом `.dark` | Атрибут `data-theme` на `<html>`; класса `.dark` в проекте нет (§2.1.1) |
| Кнопки и поля на **React Aria** | Radix UI + CVA + `cn()`; React Aria в проекте не используется (§0) |
| Радиусы полей `rounded-[12px]`, кнопок `rounded-[14px]` | Шкала `--radius-*`: поля и кнопки `rounded-md` (10px), карточки `rounded-xl` (14px), модалки `rounded-4xl` (§2.3) |
| Резерв под ошибку `min-height: 76px` | `min-h-[1.5rem]` у блока подсказки/ошибки (§3.3, No-CLS) |
| Высота хедера `52px` | 72px desktop / 64px mobile; legal-шапка — `h-14` (§2.6, §3.7) |
| Метрики: «Poppins Bold» | `font-display` + `text-headline-sm` (weight 500) в `MetricCard` (§3.4) |
| Три брейкпоинта (mobile/tablet/desktop) | Стандартные Tailwind v4: `sm`/`md`/`lg` (+`xl`), §4.1 |
| Ссылка на `docs/design-system-ux42.md` как на источник правил | Источник истины — `src/app/globals.css`; `docs/ui/design-system-ux42.md` — **спека для Figma** (§8) |

## Что из старого документа всё ещё актуально

Четыре правила перенесены без изменений и теперь живут в каноническом документе:

1. **Сетка 4px** — §2.3 (отступы).
2. **No-CLS:** под полем зарезервировано место под ошибку — §3.3.
3. **Зона клика ≥ 44×44px** — §2.6 и §5.1.
4. **Только `lucide-react`**, никаких других иконочных библиотек — §0 (стек).

## Если вы нашли расхождение между кодом и документацией

Не правьте этот файл. Откройте §9 (`Docs/design-system.md`) — там есть список
известных расхождений с приоритетами и точными файлами. Новое расхождение
добавляется туда же, а не в отдельный «rules»-документ.
