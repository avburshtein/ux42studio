# Кнопки интерфейса — актуальная спецификация

**Сверка:** 30.10.2026 · UX42.studio.   **Репозиторий:** avburshtein/ux42studio. HEAD при исследовании: e0da3f5342248f1a2511c1cf26e58b4fa2f446e9.   **Статус:** описание существующей реализации, не новый единый дизайн-стандарт.

## 1. Охват и правила чтения

Охвачены кнопки публичных страниц, профиля и кейса; auth, admin и super-admin; локальные редакторы, загрузка и галереи. Смежные интерактивные элементы описаны отдельно, чтобы не смешивать ссылки, команды и переключатели.

В проекте нет одного универсального Button: публичный CtaButton, базовый ui/Button и локальные элементы отличаются. Одинаковое название варианта не гарантирует одинаковый вид. **Secondary публичного CTA — outline с тенью; secondary ui/Button — заливка secondary-container.**

Размеры — px. Hex — стандартная тема; пользовательские M3-темы могут менять токены. Описаны явно заданные состояния. Отсутствие собственного focus-стиля не означает отсутствие браузерного индикатора. Selected / checked / open не равны pressed / :active.

Проверены определения и места применения; где использование в текущих маршрутах не подтверждено, это отмечено. Production, итоговый CSS, браузерное поведение, реальные данные и успешность операций не проверялись.

## 3. Публичный CtaButton — 4 варианта

Общее: h56, padding-x32, gap8, pill, Inter Medium16/24, nowrap, hug; центрирование по обеим осям.

| **Вариант** | **Default** | **Hover** |
|---|---|---|
| primary | primary/on-primary, S0 | opacity90% + S1 |
| secondary | border1 primary-container, фон lowest, текст on-background, S0 | фон primary5% через color-mix + opacity90% + S1 |
| ghost | прозрачный, без рамки/тени, on-background | opacity70% |
| link | прозрачный, primary, без исходного underline | underline, offset4 |

Все имеют F2. Transition150ms ease-out: primary — тень/opacity; secondary — также фон; ghost/link — opacity. Underline link этим переходом не анимируется.

Всегда ссылка, не командная кнопка. external=true: новая вкладка, noopener noreferrer. Иконки передаются содержимым; автоматических стрелок нет. API size/disabled/loading и отдельного :active нет.

## 4. Базовый ui/Button — 6 вариантов × 4 размера

Формы и административные действия. Нативный button, inline-flex, центрирование, radius10, Inter Medium16/24. Default variant=default, size=default.

| **variant** | **Default** | **Hover** |
|---|---|---|
| default | primary/on-primary | opacity90% |
| destructive | error-container/on-error-container | opacity90% |
| outline | border1 outline, прозрачный фон, on-surface | фон surface-variant |
| secondary | secondary-container/on-secondary-container | opacity90% |
| ghost | прозрачный, on-surface | фон surface-variant |
| link | прозрачный, primary, underline-offset4 | underline |

| **size** | **Размер** | **Padding** |
|---|---|---|
| default | h40, hug | x16/y8 |
| sm | h36 | x12; y отдельно не задан |
| lg | h44 | x32; y отдельно не задан |
| icon | 40×40 | отдельно не задан |

Размер не меняет типографику. Автоматических размеров иконки/gap нет. Нет встроенных nowrap, тени, min-width, shrink-0 и asChild. Локальный className может переопределять значения.

- Focus-visible: outline-none, ring2 primary, offset2; цвет offset самим Button не задан.
- Disabled: native disabled, pointer-events none, opacity50%.
- Loading: API отсутствует, собирается вызывающей стороной.
- Pressed: active-заливка/ripple/scale/aria-pressed не встроены.
- Transition-colors, без локально заданной длительности; отдельной анимации hover-opacity нет.
- Type не задан автоматически: внутри формы без type действует браузерный submit.

## 11. Загрузка, удаление и crop

**GridSlot Replace:** p6/icon16, номинально28×28, white90%→white/shadow-sm; появляется по hover карточки. Есть aria-label, нет явного focus-reveal/per-slot pending.

Caption — текстовая команда с cursor-text; Enter/blur сохраняют, Escape отменяет. Readonly скрывает delete/drag и блокирует caption.

Switch в DesignSystemColors меняет образцы схемы, не глобальную тему сайта. На проверенных admin-страницах видимость/publish/custom theme используют checkbox, не Switch. Checked/open нельзя документировать как pressed кнопки.

## 14. Расхождения и границы

1. Не унифицировать задним числом h56/h58/h48 CTA, h40/h36/h44 ui/Button и маленькие12/24/28 площадки редакторов.
2. Ghost/outline/destructive/link имеют разные локальные реализации. Back кейса — background-hover, CTA ghost — opacity-hover; prototype link без underline.
3. Фильтры главной/профиля отличаются тенями, семантикой, mobile. Жёсткие зелёные hover-фоны не следуют seed.
4. Нет единого pressed/loading/success API, обязательного spinner и общей защиты от повторной отправки. Disabled-ссылка не равна native disabled-button.
5. Focus/keyboard не унифицированы. Hover-only delete/replace, маленькие площадки и category/preset без toggle-семантики требуют отдельной проверки. Не везде есть focus trap/возврат.
6. Токены FAB и primary-variant AuthBar требуют проверки CSS. Hex стандартной темы не гарантируют вид пользовательского профиля.
7. Потенциально несогласованные цели: #portfolio у части ссылок при id=work; Hire me кейса по умолчанию #contact, но текущий маршрут такого id не создаёт. Переходы не проверены runtime.
8. Исторические Figma-спеки содержат градиенты, bounce, pressed-opacity и размеры, которых сейчас нет. Не переносить без отдельного решения.
